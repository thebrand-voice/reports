Call Reports

Live URL: https://reports.yourbrandvoiceai.com

A simple form for logging Field Meeting and Phone Call reports and emailing them to the team. Works in any phone or desktop browser — no login, no app install.

Opening it

Go to reports.yourbrandvoiceai.com in Safari, Chrome, or any browser. Bookmark it or add it to your phone's home screen for quick access (Safari: Share icon → Add to Home Screen).

Recipients (top of the page)

Right under the tabs, you'll see three fields:

To — who the report gets emailed to
CC (optional) — a second recipient
Compose from this Gmail account (optional) — useful on desktop if you're signed into more than one Gmail account, so it opens the draft from the right one

These are saved automatically as you type, but only in that specific browser on that specific device. If you use the form on a different phone, computer, or browser, you'll need to enter the recipients there too the first time.

Filling out a report

Pick Field Meeting or Phone Call at the top. Fill in whatever fields apply — every field is optional. As you type, your entries autosave in the background, so if you accidentally close the tab or your phone locks, your progress is still there when you come back.

The four buttons
Save & Email

Saves the report to the Saved tab, then opens a pre-filled email draft (To, subject, and body all filled in) in your phone or computer's mail app. You still have to tap Send yourself — nothing goes out automatically. This is intentional, so you can review each report before it's sent.

Note: this does not attach a file. If you want the Word document attached, use Download .docx first (see below), then attach it in the same draft.

Download .docx

Downloads the report as a real Word document.

On iPhone:

Tap Download .docx. Safari shows a "Download complete" notification, and the file lands in the Files app, usually under Downloads (or iCloud Drive → Downloads, depending on your Safari settings).
Open your email draft (from Save & Email, or start a new one).
Tap the attachment/paperclip icon in the compose window.
Tap Browse, find the file in Downloads, and select it to attach.

On Android: the file downloads through Chrome the same way any file does — check your Files or Downloads app, then attach it in Gmail the same way (paperclip icon → Browse/Files).

Print / Save PDF

Opens your device's print dialog with a clean, full-text version of the report (not the form itself).

On a computer: choose "Save as PDF" as the destination instead of a physical printer.
On a phone: turning the print preview into an actual PDF file depends on what your phone/browser offers at that screen — some show a Save to Files or Save as PDF option directly; others may need a PDF-capable app installed to save or share it as a file. If you don't see a save option, printing to an actual printer (or AirPrint) will still work from the same screen.
Clear

Wipes every field on the current tab. This cannot be undone, and it does not touch anything already sitting in the Saved tab — only clears the form.

The Saved tab

Every report you've sent via Save & Email is listed here, most recent first, with two options: Email again (re-opens the mail draft) or Delete.

How long these last: indefinitely — refreshing the page, closing the browser, or restarting your phone does not delete them. They're stored in that browser's local storage, so they're only lost if:

someone clears that browser's site data/cache,
the form is used in a private/incognito window (wiped when the window closes), or
you switch to a different browser or device (each has its own separate storage — nothing syncs between them).

There's no cloud backup — if a browser's data is cleared, those saved reports can't be recovered. Treat the Saved tab as a short-term convenience, not a permanent archive.
